## 🎯 Para quem é

Para quem já criou seu primeiro resource e quer ir além: **interfaces visuais** (menus, painéis, HUD) e **dados persistentes** (que continuam salvos depois que o servidor reinicia).

> **Pré-requisitos:** [Lua do Zero](https://github.com/kennedy-hkdv/ebook-lua-do-zero) e [FiveM: Primeiros Passos](https://github.com/kennedy-hkdv/ebook-fivem-primeiros-passos). Noções de HTML, CSS e JavaScript ajudam bastante.
